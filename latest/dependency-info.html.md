# Maven Coordinates

## [Apache Maven](#apache-maven)

```
<dependency>
  <groupId>network.ike</groupId>
  <artifactId>ike-java-support</artifactId>
  <version>2</version>
</dependency>
```

## [Apache Ivy](#apache-ivy)

```
<dependency org="network.ike" name="ike-java-support" rev="2">
  <artifact name="ike-java-support" type="jar" />
</dependency>
```

## [Groovy Grape](#groovy-grape)

```
@Grapes(
@Grab(group='network.ike', module='ike-java-support', version='2')
)
```

## [Gradle/Grails](#gradle-grails)

```
implementation 'network.ike:ike-java-support:2'
```

## [Scala SBT](#scala-sbt)

```
libraryDependencies += "network.ike" % "ike-java-support" % "2"
```

## [Leiningen](#leiningen)

```
[network.ike/ike-java-support "2"]
```
